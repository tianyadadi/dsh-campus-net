# v0.3.0 — 流量统计 / 在线时长 / 多账号 / 非上网时段自动重试

四个功能，都是为了「少动手」：以前得自己盯、自己点的事，现在插件替你盯着。

## 1. 流量统计

- 面板显示 **今日 / 本次登录 / 开机以来**，上下行分开
- 数据源是 `netstat -e` 的全机聚合累计值，靠前后采样做差
- 30 秒节流，面板每 3 秒轮询不会真的每次都读
- 计数变小（机器重启过）时把当前值当增量，不会算出负数或天文数字
- 跨天自动归档，只留最近 7 天
- **第一次运行只建立基线**，今日从 0 起 —— 不会把「开机以来」误算成「今天」

⚠️ 读的是全机计数，**所有网卡合在一起**，不区分哪张卡。

## 2. 在线时长

面板显示「已连 2 小时 13 分」。起点在登录成功那一刻记，断开自动清零。

## 3. 多账号

`core/campus-net.json` 支持 `accounts` 数组 + `current`：

```json
{ "accounts": [
    { "name": "宿舍",   "username": "111", "password": "p1" },
    { "name": "实验室", "username": "222", "password": "p2" }
  ], "current": 0 }
```

- **老配置零迁移**：没有 `accounts` 时，`username`/`password` 自动当成唯一账号（名字叫「默认」）
- 多于一个号时面板变成下拉框，选了立刻生效
- 切号会把选中账号镜像回 `username`/`password`，`救急重连.cmd` 等老调用方不用改
- 在线时切号不会踢掉当前会话，只影响下次登录

## 4. 非上网时段自动重试

学校在非上网时段返回「不允许上网时间段，请在上网时段认证」。
以前遇到就停在那儿。现在：

- 识别到这类错误 → 每 10 分钟自动试一次，最多 60 次（≈10 小时）
- 连上就停；手动登录成功也立刻停
- 面板显示「⏳ 现在是非上网时段，8 分钟后自动重试（第 3/60 次）」

重试逻辑单独放在 `retry.js`，就是为了能单测 —— 测试里把间隔调成 50ms 跑，
不用真等 10 分钟。

## 新接口 / 新命令

| 类型 | 内容 |
|---|---|
| 接口 | `POST /api/campus-net/switch-account`（body: `{index}` 或 `{name}`） |
| 接口 | `status` 多了 `traffic` / `accounts` / `account` / `online_seconds` / `auto_retry` |
| 命令 | `traffic`、`accounts`、`switch-account <序号\|名字>` |

## 升级

```bash
dsh plugin --profile desktop add link:<本目录绝对路径>
```

然后**重启 DSH**（服务端路由和挂件都变了）。
