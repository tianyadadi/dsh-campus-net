# v0.3.1 — 开机自动连接修复

小版本，只修一个问题：**开机后插件不自己连，得去浏览器手动点一次**。

## 症状

- 一开机就打开 DSH，挂件显示「未连接」，但下载/上传都有速度
- 必须自己去浏览器打开任意网页，才连得上
- 之后再点「连接」是好的，只有开机那一次不行

## 根因

`kick()` 只做一件事：DSH 启动 **8 秒后**跑一次 `ensure`，失败就结束。
而 `retry.js` 的自动重试只认「不允许上网时间段」这类错误，
**「拿不到门户参数 / 连不上门户」不在重试范围内** → 一次失败 = 永久放弃。

开机那会儿网卡刚拿到 IP、门户还没就绪，探测 `http://2.2.2.2/` 12 秒超时是常态，
所以这个失败几乎是必然的。

## 现在

启动自检改成**退避重试**：

```
第 1 次 8s → 第 2 次 +15s → 第 3 次 +25s → 第 4 次 +45s
第 5 次 +60s → 第 6 次 +90s → 第 7 次 +120s → 第 8 次 +180s
```

- 约 6 分钟内最多试 8 次，**连上立刻停**
- 每次写日志：`启动自检 #3：已登录` / `启动自检 #3：失败：拿不到门户参数…`
- 8 次都失败才放弃，不影响手动点「连接」
- 开机时确实不在校园网（比如连了热点）也不会反复弹，试完就安静停下

## 另一处说明

未认证时挂件也会显示下载/上传速度 —— 那是**网卡实际收发的流量**，
局域网和门户本身也有数据。面板上补了一行说明，别把它当成「已联网」。

## 升级

插件是 link 安装的（本地源码），**重启 DSH 即生效**，不用重装。
