# v0.1.0 — 首个可用版本

校园网（Srun 深澜）连接器，给 DeepSeek Harness 侧边栏加一只常驻挂件。

## 功能

- **实时测速** — 上传 / 下载速率，折叠态 3.5 秒刷新，展开态 2 秒
- **一键开关** — 连接 / 断开校园网
- **自动识别网络** — 按默认路由判定：手机热点 / WiFi / 有线 / 校园网，显示对应名字和图标
- **断开保护** — 断开后 30 秒自动重连，避免把自己锁在外面
- **开机自动连** — DSH 启动 8 秒后自检，离线就登录
- **位置可拖动** — 按住挂件拖到合适位置，松手自动记住；面板里有「复位」
- **断网自救** — 双击 `救急重连.cmd`，不依赖 DSH 也能重连

## 支持的系统

**Srun 深澜** 认证（`portalLogout.do` / `wlanuserip` / `wlanacname` 特征）。

> 不适用：Dr.COM、锐捷、需要验证码或短信二次验证的门户。

## 安装

```bash
dsh plugin --profile desktop add link:<本目录绝对路径>
```

然后：

1. 把 `core/campus-net.example.json` 复制成 `core/campus-net.json`
2. 填入你的**认证地址**、**账号**、**密码**
3. 重启 DSH
4. 跑 `python core/campus_net.py doctor` 确认四项全绿
